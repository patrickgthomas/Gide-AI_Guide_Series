# Gide AI Guide Series

Companion pages for two of the free Gide AI guides, hosted on GitHub Pages:

- `index.html` — *AI Won't Replace You*, with its companion podcast episode and
  the AI Wayfinder slideshow.
- `goldrush.html` — *The AI Gold Rush*, with its companion video and podcast episode.

Both pages set `rel="canonical"` to the corresponding book page on
[gidehub.com](https://gidehub.com/books/), which is the primary home for the
series. These pages exist because the audio, video, and EPUB files in this
repository are not duplicated on the main site.

`assets/css/gide.css` and `assets/js/nav.js` are copies of the shared Gide design
system from the main site repo. Refresh them by copying the files across rather
than editing them here.
